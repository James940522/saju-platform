# 서버 없이 화면 시연하기

현재는 `NEXT_PUBLIC_DEMO_FALLBACK`을 설정하지 않아도 서버 연결 실패 시
예시 데이터로 전환한다. 기존 화면 컴포넌트와 API 응답 mapper를 사용한다.

## 동작

- API 주소가 없는 production 빌드에서는 바로 미리보기를 연다.
- API 주소가 있으면 실제 서버를 먼저 사용한다. 조회는 최대 3초 기다린 뒤
  네트워크 오류, timeout, 5xx, API가 아닌 응답이면 미리보기로 전환한다.
- 실제 인증 실패(401/403), 입력 오류, 유효한 API의 404, 요청 제한은 유지한다.
- 미리보기에서는 OAuth 없이 예시 사용자로 UI를 볼 수 있다. 실제 인증 토큰을
  발급하지 않으며, 전환한 뒤에는 서버에 요청하지 않는다.
- 홈, 풀이 목록/소개, 내 만세력, 프로필 목록/상세/등록/수정, 계정 관리에
  예시 데이터를 제공한다. 운세, 약관, 개인정보 페이지는 기존 화면을 사용한다.
- 재물운 랭킹은 2~5명 선택, 새 참여자 추가, 예시 결과, 보관함까지 연결된다.
  처음부터 보관함에 예시 랭킹 2건을 제공한다.
- 전생 관계 예시 결과를 바로 열 수 있으며 기존 데모 결제 화면도 이용할 수 있다.
- 아직 개발되지 않은 풀이 생성 화면은 기존 준비 화면을 유지한다.
- 프로필과 랭킹 결과는 탭의 `sessionStorage`에 저장한다. 새로고침하면 유지되고
  새 탭에서는 예시 데이터부터 시작한다. 저장소가 차단되면 현재 방문 중에만 유지한다.
- 만세력은 백엔드에서 한 번 계산해 고정한 예시다. 추가 입력에 따라 프론트엔드가
  계산하거나 AI 풀이를 생성하지 않는다. 화면과 결과에 예시임을 표시한다.
- 실제 회원 탈퇴는 미리보기에서 실행하지 않는다.

## 배포 설정

| 값 | 동작 |
| --- | --- |
| 생략 또는 `true` | 실제 API 우선, 연결 실패 시 탭 전체 미리보기 |
| `always` | 서버/OAuth 연결 없이 미리보기 |
| `false` | 미리보기 비활성화, 실제 API와 인증 흐름 사용 |

대표 시연을 항상 같은 상태로 시작하려면 `NEXT_PUBLIC_DEMO_FALLBACK=always`로
프론트엔드를 빌드한다. 서버 배포 후 실제 서비스로 전환할 때는
`NEXT_PUBLIC_DEMO_FALLBACK=false`와 API 주소를 설정하고 다시 빌드/배포한다.
`NEXT_PUBLIC_*` 값은 빌드 시 브라우저 번들에 포함된다.

자동 전환된 탭은 실제 데이터와 예시 데이터가 섞이지 않도록 시연 상태를 유지한다.
서버 복구 후 기본 설정으로 확인하려면 새 탭을 사용한다. 사용자 작성 예시 결과는
해당 탭에서만 볼 수 있으며 서버의 공개 공유 결과가 아니다.
따라서 미리보기에서는 결과 링크 공유 버튼을 비활성화한다.

백엔드 계약, DB, migration은 변경하지 않는다.
